# Personal Fantasy GM Assistant

A personal, non-commercial AI-assisted fantasy football management tool built to help manage my Yahoo Fantasy Football team.

## Purpose

The goal of this project is to create an AI-assisted fantasy football manager that can analyze my league and help the GM make better decisions throughout the season.

The application is intended for personal use only and is not a commercial product.

## Planned Features

- Analyze Yahoo Fantasy Football league and scoring settings
- Monitor roster and available players
- Analyze weekly matchups
- Monitor player injuries and availability
- Recommend optimal starting lineups
- Identify waiver-wire opportunities
- Recommend player additions and drops
- Analyze potential roster moves
- Assist with ongoing fantasy team management

## Yahoo Fantasy Sports Integration

The application is being developed to integrate with the official Yahoo Fantasy Sports API using authorized OAuth access.

Yahoo Fantasy data will only be accessed through authorized API access associated with my own Yahoo account.

Read/write API access may be used to perform authorized roster-management actions such as setting lineups and submitting roster transactions.

## AI Assistance

The application will use AI-assisted analysis alongside fantasy football data to evaluate roster decisions, player availability, matchups, and other relevant factors.

Currently under development.

Personal, non-commercial hobby project. The application is currently intended for a single user.
